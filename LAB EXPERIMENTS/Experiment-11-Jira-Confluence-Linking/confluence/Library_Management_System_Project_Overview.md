## 1. Executive Summary
The **Library Management System (LMS)** project is an automated enterprise solution developed to modernize campus library operations. It provides end-to-end management of digital book search catalogues, user authentication, reservation workflows, borrowing tracking, and automated overdue tracking. 

This Confluence documentation space serves as the central collaboration portal for project stakeholders, linking live project management deliverables directly from **Jira Software** into this overview page via the Atlassian Jira Macro.

---

## 2. Project Goals & Release Scope
- **Core Objective**: Replace manual card catalogues with a centralized digital repository.
- **Key Deliverables**:
  - Full-text multi-parameter book search by author, title, and ISBN.
  - Role-based security authentication for students, faculty, and administrative librarians.
  - Dynamic checkout, renewal, and return transaction lifecycle tracking.
  - Live progress monitoring and transparency across the software development team.
