## Key Operating Decisions
1. **Framework:** Scrum tailored with Lean WIP constraints (Development: 4, Review: 2, Test: 2) to prevent QA starvation and mid-sprint bottlenecks.
2. **Stakeholder Alignment:** Strict time-boxing of warehouse and finance representatives into 45-minute backlog refinement and 45-minute sprint review sessions per week.
3. **Escalation Protocol:** Any blocker unresolved after 24 hours escalates to the Product Owner for scope substitution or technical stubbing.
4. **Tool Selection:** Jira Software selected for native epic/story hierarchy, configurable WIP limits, and Agile burndown reporting, with GitHub Projects maintained as an engineering backup.
