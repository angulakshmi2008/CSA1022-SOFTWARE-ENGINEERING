## Key Takeaways
1. **Root Causes Identified:** Discrepancies between physical and virtual inventory arise from delayed inventory decrements during checkout. Lack of public order milestones leads to support ticket saturation. Informal refund authorizations cause financial leakages.
2. **First-Release Strategy:** Prioritize an end-to-end, permission-controlled order journey (`CREATED` → `DELIVERED` → `REFUNDED`) over broad module surface area.
3. **Traceability:** Aligns with CO1, BTL 5 (Evaluate), and Task 1 (5 Marks) of the CSA10 Software Engineering assignment syllabus.
